# 质量与综合管理要点

本页面梳理了软件项目管理中除范围、进度、成本之外的其他核心领域的应试考点。

---

## 🛠️ 项目质量管理

*   **质量管理基本定义**：包含制定质量方针、质量目标，并执行质量保证 (QA) 和质量控制 (QC)。
*   **软件质量要素**：
    1.  **产品运行**：正确性、健壮性、效率、安全性、易用性。
    2.  **产品转移**：可移植性、可重用性、互操作性。
    3.  **产品修改**：可维护性、柔性、可测试性。
*   **规划阶段方法**：成本效益分析、质量成本 (COQ)。
*   **六西格玛 (Six Sigma)**：了解核心的“六 C”要素（客户、控制、协同等）基本概念。

---

## 👥 项目资源管理 (以人力资源为主)

*   **团队组织结构**：
    1.  **职能型 (Functional)**：按专业分工，部门墙深。项目经理几乎无权限。
    2.  **项目型 (Projectized)**：成员归属项目组。项目经理权限极大。
    3.  **矩阵型 (Matrix)**：强矩阵（项目经理强）、弱矩阵（职能经理强）、平衡矩阵（两权均衡）。
*   **团队建设五阶段**：
    *   **形成阶段**（Forming） $\rightarrow$ **震荡阶段**（Storming） $\rightarrow$ **规范阶段**（Norming） $\rightarrow$ **成熟阶段**（Performing） $\rightarrow$ **解散阶段**（Adjourning）。
*   **四大激励理论 (选择题常考匹配)**：
    *   **马斯洛需求层次理论**：生理 $\rightarrow$ 安全 $\rightarrow$ 社交 $\rightarrow$ 尊重 $\rightarrow$ 自我实现。
    *   **赫茨伯格双因素理论**：保健因素（防止不满意，如工资、环境）与激励因素（带来满意，如晋升、成就感）。
    *   **期望理论 (Vroom)**：激发力量 = 效价 (Value) $\times$ 期望值 (Expectancy)。
    *   **公平理论**：员工倾向于将自己的投入与产出与他人进行横向/纵向比较。

---

## 📣 项目沟通管理与冲突解决

*   **沟通核心**：对象是干系人。冲突在团队中是**必然的**，冲突具有两面性（既有破坏性，也可促进新思路）。
*   **冲突解决技术**：撤退/回避、缓和/包容、妥协/调解、强迫/命令、合作/解决问题（最理想方式）。

---

## ⚡ 项目风险管理

*   **风险分类**：已知风险（发生概率及后果明确）、可预测风险（有历史经验但具随机性）、不可预测风险（全新未知）。
*   **风险应对策略 (必考选择题匹配)**：

| 风险属性 | 应对策略 | 适用场景 | 例子 |
| :--- | :--- | :--- | :--- |
| **消极风险（威胁）** | **规避 (Avoid)** | 彻底消除威胁源（高风险） | 修改设计以避开不稳定组件 |
| | **减轻 (Mitigate)** | 降低发生概率或减轻后果 | 安排培训、多做测试 |
| | **转移 (Transfer)** | 让第三方承担损失 | 买保险、外包给分包商 |
| | **接受 (Accept)** | 预留应急储备，不主动改变 | 预留 10% 备用金 |
| **积极风险（机会）** | **开拓 (Exploit)** | 确保机会 100% 发生 | 指派最优秀的专家 |
| | **提高 (Enhance)** | 增加机会发生的概率或红利 | 增加推广预算 |
| | **分享 (Share)** | 与第三方合作共享机会 | 建立合资企业 |
| | **接受 (Accept)** | 机会来了就接着，不主动争取 | - |

## 📦 项目采购管理

*   **自制与外包决策**：核心业务自制，非核心业务且成本允许时才外包。
*   **外包安全**：外包时必须高度防范组织**核心数据泄密**风险。

---

## 🔄 项目整合管理与收尾

*   **变更控制**：任何变更都必须遵循正式的变更控制流程（提出申请 $\rightarrow$ 评估影响 $\rightarrow$ 批准/拒绝 $\rightarrow$ 实施变更 $\rightarrow$ 动态更新项目文档）。
*   **收尾分类**：
    *   **正常结束**：进行项目移交（移交产品与运营）。
    *   **非正常结束**：进行项目清算（非正常终止，清算账目与资产）。
*   **项目验收**：包含**质量验收**（可交付成果合格）与**文件验收**（项目过程文档齐全）。
*   **项目后评价**：项目彻底结束、运行一段时间后，对其效益和影响进行的总结评价。
